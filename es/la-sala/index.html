La sala

Una sala amplia y luminosa, solo para vosotros, con todo lo necesario para montar vuestra celebración.

Durante vuestra reserva el local es exclusivo para vosotros: traéis vuestra comida, bebida, tarta y decoración y lo preparáis a vuestro gusto.
