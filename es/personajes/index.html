Personajes para vuestra fiesta

Disfraces de personaje para que alguien del grupo se lo ponga y dé la sorpresa. Para vuestra celebración en Hiluma o para llevároslos a otra fiesta.

Elegid vuestros personajes

Tocad las fotos para marcar los que queráis. Podéis elegir varios.

Es un extra aparte: los personajes no entran en el precio del local. Preguntadnos por WhatsApp el precio y las condiciones, tanto para usarlos aquí como para alquilarlos y llevároslos.

Pedidlos por WhatsApp

Elegid si los queréis para una fiesta en Hiluma o para llevar, y se abrirá WhatsApp con vuestros personajes ya escritos.

Al pulsar se abrirá WhatsApp con tu mensaje ya escrito; solo tienes que enviarlo. Esta web no guarda tus datos.
